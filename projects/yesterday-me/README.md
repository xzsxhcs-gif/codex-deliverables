# 昨日的我

**跨时空自我审判系统**。今天封存留言，明天看看昨天的自己说了什么，再决定无罪释放还是轻轻哈一口气。这是时间胶囊与轻松角色扮演，不是自我批评工具。

Vue 3 + Vite + TypeScript，IndexedDB 本地存储，无需账号、业务服务器或付费 API，无广告与第三方追踪。支持手机竖屏、桌面、深浅主题、减少动态效果、离线访问及 PWA 安装。

## 本地运行

需要 Node.js 22.12+（推荐当前 LTS）和 npm。

```bash
npm ci
npm run dev
```

打开终端显示的地址。生产构建及预览：

```bash
npm run build
npm run preview -- --port 4175
```

开发服务器用于开发；离线缓存与安装请使用生产构建，并通过 `http://localhost:4175` 或 HTTPS 访问。手机访问电脑的普通局域网 HTTP 地址时，浏览器通常不会启用 Service Worker 或安装能力。

另附已构建的 `yesterday-me-app.zip`。它包含 `dist/` 与一个没有第三方依赖的静态预览脚本：解压后执行 `node scripts/serve.mjs`，打开 `http://localhost:4173` 即可使用，不必先安装 npm 依赖。它只提供应用静态文件，不接收或保存你的留言。

## 使用流程

1. 在「封存」填写标题、留言、预测，可选填写辩护词。点击「封存证据」后，界面不再提供查看或修改入口。
2. 封存时当地日历的下一天，从 00:00 起获得解锁资格。可以晚些天再打开，不会过期；不能补写昨天的胶囊。
3. 在「待审」打开已解锁证据：先读原文，再展开辩护词，然后选择「无罪释放」或「对自己哈气」。
4. 判决提交后才揭晓预测。判决不可改，但可在「档案」重复查看，并按结果筛选、切换日期顺序。
5. 「统计」仅计算实际记录，不含演示数据。设置中可以备份、导入和清空数据。

预测中的「不好说」不计入准确率分母。连续原谅天数按当地日历日计算：当天至少释放一次且没有哈气才计一天；今天未审判时可接续昨天，今天哈气则归零。最常审判的星期统计的是判决发生日，支持并列结果。

## 日期、持久化与安全边界

解锁依据是**本地日历日期**，不是经过 24 小时。23:59 封存的胶囊可在次日 00:00 打开；夏令时跨日也使用日历规则。封存时记录当地日期与时区，之后按当前设备的当地日期与记录的解锁日期比较。因此旅行切换时区、修改设备时间，都可能改变何时具备解锁资格。

封存是正常界面的访问规则，**不提供密码学安全保护**。设备所有者仍可能通过开发者工具、备份或修改本地数据读取内容；本应用不是无法破解的保险箱。导出的 JSON 包含全部原文、未揭晓预测和辩护词，请将备份当作私人日记保管。

数据保存在当前浏览器、当前网站来源的 IndexedDB。刷新、关闭后重开不会主动删除记录，但清理浏览器数据、无痕模式结束、浏览器存储回收、卸载应用或更换访问地址可能使数据丢失或不可见。不同浏览器、域名、端口和设备之间不会自动同步，建议定期导出备份。

导入会严格校验格式、日期、判决等字段；最多 10 MB、10,000 条。导入是原子合并，不覆盖已有证据或判决：相同记录跳过、相同 ID 的不同记录计为冲突、编号碰撞重新分配。清空数据需要二次确认且不可撤销，建议先导出。

## 安装、离线与更新

首次在线访问生产网站并加载完成后，静态资源会被 Service Worker 缓存；之后可以离线打开、封存、审判和查看已有记录。胶囊内容不会被上传或写入网络缓存。

- 安卓 Chrome：浏览器菜单 →「添加到主屏幕」或「安装应用」。浏览器支持时，设置中也会显示安装入口。
- 桌面 Chrome / Edge：地址栏安装图标，或浏览器菜单中的安装选项。
- iPhone Safari：分享 →「添加到主屏幕」。

安装不是必需的，应用不要求通知权限。关闭应用期间无需后台倒计时，重新打开时会按当前当地日期重新判断解锁资格。新版本可用时会提示更新；已封存的数据仍保留在 IndexedDB，建议在更新前先处理尚未封存的输入。

部署时将 `dist/` 上传到任意 HTTPS 静态站点即可；无需后端。项目使用相对资源路径与 hash 导航，支持子目录部署。不要使用文件管理器直接打开 `dist/index.html`，浏览器安全限制会阻止模块与离线功能。

## 测试

```bash
npm test
npm run build
npm run test:e2e
```

单元测试覆盖当地跨日、夏令时、封存校验、未解锁访问、预测延迟揭晓、不可重复审判、事务及导入边界、持久化与真实统计。

Playwright 直接测试生产构建，自动启动 `vite preview` 于端口 4175。存在 `/usr/bin/chromium` 时优先使用它；其他环境可先执行 `npx playwright install chromium`，或用 `CHROMIUM_PATH=/path/to/chromium npm run test:e2e` 指定本机 Chromium。测试通过浏览器时钟模拟午夜，并从正常界面封存证据，不在产品中植入测试后门；同时验证备份、窄屏、PWA、离线刷新和减少动态效果。失败记录保存在 `test-results/`，HTML 报告在 `playwright-report/`。

持久化测试除了刷新和新标签页，还会启动一个使用临时磁盘配置目录的真实 Chromium：从界面封存后完全退出浏览器，再以同一配置目录启动新的浏览器进程，验证证据、主题和引导状态保留，并在模拟次日读取原文。此测试不使用 `storageState` 恢复，也不直接写入测试数据库；结束后删除临时配置目录。

## 工程结构

```text
src/
  App.vue                 应用外壳、引导、设置及对话框
  components/             案件详情、可访问对话框、图标
  views/                  封存、待审、档案、统计页面
  composables/            应用状态及 PWA 生命周期
  domain/
    calendar.ts           当地日历日期与午夜边界
    repository.ts         IndexedDB、封存、判决、导入导出
    stats.ts              真实记录统计
    types.ts              数据及页面契约
public/                   本地生成图标与静态资源
tests/                    单元测试与 Playwright 端到端测试
vite.config.ts            Vue、PWA、静态部署配置
```

界面只通过数据层访问胶囊。数据层对锁定摘要隐藏标题、正文、辩护和预测，审判完成前也不返回预测；封存与判决在 IndexedDB 事务中执行，以避免重复点击或多标签页造成重复判决。
