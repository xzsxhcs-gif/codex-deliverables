# v1 验收记录

本版本为 Vue 3 + Vite + TypeScript 本地优先 PWA，没有后端、账号、付费 API 或追踪脚本。全部统计来自 IndexedDB 中的实际记录，初始数据库为空。

## 完成的体验

- 可选标题、必填留言、三种预测、可选辩护；每日多条封存，封存成功后清空草稿。
- 封存时记录当地日期和时区，次日当地日历日期起可解封，晚些日子仍可打开。正常界面不提供补写昨日入口。
- 锁定列表不返回标题、正文、辩护或预测；解锁后先原文，再展开辩护；判决前仍不返回预测。
- 两种不可修改的判决、轻量动画、场景匹配的随机幽默文案、预测结果揭晓。不确定预测不算错误。
- 可反复查阅的档案、正反日期排序、判决筛选，以及所有要求的真实统计。
- 首次引导、深浅主题、手机底部导航、键盘焦点与原生模态框、减少动态效果偏好。
- 明文 JSON 备份、严格导入校验、原子合并、冲突保留现有记录，输入「删除」后的第二次确认才会清空数据。
- 离线启动与操作、安装 manifest 和 maskable 图标；新版本先提示，确认前保留正在编辑的草稿。

## 实际结果

| 检查 | 结果 |
| --- | --- |
| Vue / TypeScript 与 Vite 生产构建 | 通过 |
| Vitest 单元与集成测试 | 71 / 71 |
| Playwright 生产浏览器流程 | 8 / 8 |
| 独立子目录 PWA 与更新检查 | 10 / 10 |
| 浏览器完整关闭并从同一磁盘 profile 重开 | 记录、主题、引导状态保留 |
| 320 / 390 / 1280 像素布局 | 无横向溢出 |
| 真实断网刷新、封存与重新读取 | 通过 |

测试模拟当地午夜、夏令时 23/25 小时日、跨月年、时区旅行、设备日期回退、并发事务与不同标签页。重复审判仅有一次能成功；其他标签页中的宣判或删除会同步到已打开的详情。

修复了保存已提交但刷新失败被误报为保存失败的边界：现会保持已提交成功结果并提示重新读取，不要求重复封存。日期回退时会立即关闭尚未判决的已解锁详情并重新隐藏摘要，不依赖数据库刷新成功。

测试没有给生产版本添加模拟解锁、虚构统计或直接填写昨天日期的入口。浏览器测试通过真实界面创建记录，并仅使用测试工具的时钟模拟跨日。

## 已知边界

封存是正常界面的时间访问规则，不是加密保护。设备所有者能通过系统日期、开发者工具或明文备份访问、改变本地数据。清除网站数据可能造成丢失，持久存储许可不能代替备份。应用没有跨设备自动同步。

本次在 Linux / Chromium 中验证；未操作实体安卓手机。普通局域网 HTTP 不满足安装与离线的安全来源要求，请使用 localhost 或 HTTPS。在线托管所需的 GitHub Pages 启用权限被当前连接拒绝（HTTP 403）；静态文件已经放在仓库 `docs/`，所有者可按 README 一次性启用。

原始 JSON 测试结果与构建文件 SHA-256 清单随验证资料包交付。
