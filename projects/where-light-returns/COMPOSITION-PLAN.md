# 微光归途 / Where Light Returns

在生成音符前确定的创作设计。2026-10-23。

## 音乐骨架

- 纯音乐，约90秒；4/4，32小节。
- D大调，以相对B小调的 Bm9 开场；由含蓄、带悬念的色彩逐渐走向明亮的D大调。
- 第1–28小节90 BPM；第29–32小节从90逐渐减速到70 BPM。起始留0.3秒空间，尾部3秒自然释放，总长约90.03秒。
- 核心动机：F#4（半拍）–A4（半拍）–D5（一拍半）–C#5（半拍）–B4（半拍）–半拍休止。记忆点是上行三度、四度与短／短／长节奏；结尾向下回落。
- 本次按音高、节奏与和声新写，不复制仓库示例旋律，不使用随机音高填充。仅对演奏微时差和力度使用固定种子的极小变化。

## 曲式与配器

| 小节 | 作用 | 主要安排 |
|---|---|---|
|1–4|开场|钢琴呈示主题前半；低声部是稀疏、宽间距的音，不铺满节奏。|
|5–12|发展|完整八小节主题；大提琴先进入，弦乐随后缓慢展开，竖琴增加少量光泽。|
|13–20|推进|钢琴轻八分音型，小提琴动机发展，长笛在空隙中回答；圆号只作内声部支撑。第20小节末留出呼吸。|
|21–28|高潮|小提琴展开主题，弦乐、大提琴慢对位、圆号和竖琴共同支撑。只有主题头局部提高八度，最高D6，避免整段高八度刺耳；定音鼓与钹只落在少数结构点。|
|29–32|回归|撤去圆号和打击乐，回到原钢琴主题；渐慢、渐弱，经Em7/A7回到Dadd9，给尾音留空间。|

## 和声与连接

- 主题：Bm9 → Gmaj9 → D/F# → Aadd9/A7 → Bm7 → Gmaj9 → Em7/A7 → Dadd9。
- 将原草案的 Asus4 改为 Aadd9，避免旋律 C# 与持续D形成不必要的强烈半音摩擦。
- 推进：Em7 → Bm7/F# → Gmaj9 → Aadd9 → Bm7 → D/F# → Gmaj9 → A7。
- 高潮：Dadd9 → A/C# → Bm7 → Gmaj9 → D/F# → Em7/A7 → Gmaj7/A7 → Dadd9。
- 回归：Gmaj9 → D/F# → Em7/A7 → Dadd9。
- 弦乐主要在G3–C#5，钢琴伴奏低于主题；大提琴B2–D4，圆号D3–F#4。高声部采用共同音和小幅连接，低声部有方向，避免所有乐器始终平行加倍。

## 声音与实现

使用参考仓库自带 GeneralUser GS v2.0.3；复用 compose_kit、TinySoundFont 和 mix_kit。九个实际乐器通道：钢琴、大提琴、小提琴、弦乐合奏、长笛、圆号、竖琴、定音鼓、管弦钹。

声像按小型管弦乐场景分布；不用强Haas扩展破坏单声道兼容。钢琴保留较直接的轮廓，弦乐／长笛混响略多，低频和打击乐混响克制。渐强主要依靠乐器进入、声部密度和CC11表情，不靠母带突然变响。保留动态，检查峰值、分轨能量、段落RMS、释放尾音和MIDI／音符数据的一致性。
