# 原版保留与存档说明

## 原始参考

`reference/synthetic-clawd-original.html` 保留用户第一个 ZIP 中的完整 `index.html`。`reference/ActionWeaponKit/` 保留第二个 ZIP 的目录与文件。参考副本不参与游戏执行，也不要求 Unity。

## 合成游戏保持的内容

- 360×560 逻辑棋盘、八级角色、颜色、像素部件、眼睛与王冠画法。
- 原有重力、圆形碰撞解算、摩擦、碰撞旋转、倒立停留、地面角速度衰减。
- 随机前三档投放、拖动瞄准、松手投放、投放间隔、交换机制。
- 原有合成分数、连击、蟹王合成奖励与爆散逻辑、最高分更新。
- 图鉴、原有四项隐藏成就及对应装饰、中英切换、深浅色配色。
- 原有 Web Audio 合成音效、静音按钮、满线判负和重新开始。

`src/legacy/merging.js` 从原 HTML 中分离脚本；`index.html` 保留其布局与样式。集成修改集中在：蟹王真实合成后发出事件、暂停/恢复桥接、双语/静音状态联动、新奖励绘制、单帧循环向 3D 分发时钟，以及开发模式测试夹具。没有替换原合成物理或计分算法。

## Boss 接入点

只有从两个倒数第二级角色的正常碰撞生成最终级蟹王时才触发首次觉醒；读取图鉴或画出蟹王缩略图不会触发。模式门控防止同一转场重复创建 3D 实例。

进入战斗时原局留在内存中并冻结。胜利或主动退出后释放 3D 场景并恢复该棋盘；重试只重置战斗状态。解锁后，图鉴中的重战按钮可以再次开启遭遇。

原版没有背景音乐，只有短合成音效，因此没有可淡出的原版音乐轨。本次新增的战斗音效与转场音由 Web Audio 合成，经过独立 master gain，可静音与调整战斗音量。

## 存储键

| 键 | 内容 | 本次处理 |
| --- | --- | --- |
| `sc_best` | 原版最高分 | 继续读取和更新同一键 |
| `sc_disc` | 八级图鉴位掩码 | 保留原格式 |
| `sc_ach` | 原版四项成就位掩码 | 保留原格式，不借用额外位 |
| `sc_lang` | `en` / `zh` | 原版与战斗共用语言 |
| `sc_boss_unlocked` | 是否已开启王室遭遇 | 新增独立键 |
| `sc_kingslayer` | 是否击败蟹王 | 新增独立键；驱动称号与王冠星辉 |

“重置图鉴/成就”仍按原版确认文案处理原图鉴与四项成就；不清除最高分、本局或语言。本次新增的王室解锁与弑王者记录独立保留，不把原按钮静默扩展为删除新记录。

当前棋盘、当前分数、当前战斗生命值和攻击状态均为内存数据。跨模式切换保留棋盘，刷新或关闭页面开启新局。浏览器禁止持久存储时仍可游玩，但持久解锁无法保证写入。

## 来源隔离

`localStorage` 受浏览器来源隔离。保留键名可以延续同一来源上的旧记录，不能自动读取另一个域名、端口、协议、浏览器或设备的数据。项目不提供伪造的“自动跨来源迁移”，也不会清空浏览器的其他数据。

## 测试夹具

开发模式的 `window.clawd2D.testing.seedKingMerge()` 放入两个倒数第二级角色，后续仍经过实际碰撞、合成、原计分和觉醒事件。该夹具会重置当前测试局，不是正常玩家功能；生产构建不提供它。`window.clawdQA` 同样仅用于开发环境的自动化检查。
