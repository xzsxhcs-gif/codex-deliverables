# SNICKERS：文明的底层代码

50 秒，1080×1920，30 FPS，150 BPM。包装、字样、文明符号及视觉效果全部由程序绘制，不使用现成士力架图片或视频。原创程序化音乐，无外部配乐素材。

时间线：0–6.4 秒生成；6.4–16 秒识别、拆解与漫画剪辑；16–32 秒图腾／宗教／几何／星图／徽章／公式／电路／信息文明；32–44.8 秒回收、粒子重组；44.8–50 秒普通包装静置与冷淡收尾。

核心造型由同一套八个字母路径、长条包装轮廓及红蓝白棕配色产生。文明符号必须保持可追溯的形状关系。浏览器预览与离线渲染调用同一个 `renderFilm(ctx,t)`，所有状态可由时间直接计算。

阶段性源码保存到本仓库；最终 MP4、音轨、源工程压缩包及审片材料上传到 GitHub Release。仅在实际生成并验证后报告已交付。
