## 创作要求检查

| 要求 | 实现与检查 |
| --- | --- |
| 从零绘制士力架 | 八个字母均为手写矢量路径，包装由投影多边形、褶皱线、色块与边框组成；未导入士力架图片、照片或视频。 |
| 生成过程可见 | 起始四种色块、坐标线与字形描边，逐步形成包装；继以漫画分格、分层剖解、切片与字形基因盘。 |
| 文明演化保持遗传关系 | 同一套八个字母轮廓及固定采样索引，依次变为图腾、花瓣纹样、几何、星图、徽章、公式图谱、电路与数字节点。初版过于接近字母装饰，已改为顶点变形与轮廓重构。 |
| 文明结构回收 | 折叠档案面板、节拍字形特写、512 个真实轮廓采样点及包装条带共同回到包装位置。43.2 秒形成完整对象。 |
| 有节奏的爆发与停顿 | 150 BPM 原创合成音轨、每拍 12 帧；文明段配器变化，回收段增加事件密度，44.8 秒骤停。 |
| 荒诞收尾 | 从宏大结构切回浅色背景中的普通包装，短句“就一根。”；最后半秒纯黑与数字静音。 |
| 完整工程 | TypeScript / Canvas / Vite，Python 音乐生成，FFmpeg 编码；浏览器与离线调用同一个绝对时间渲染函数。 |

所有视觉和声音均由项目内代码生成；章节字体使用附带许可证的 Noto 字体子集。字样采用艺术化矢量近似，不是对真实包装照片的复制。

## 实际验证

- `npm run build`：类型检查及生产构建通过。
- `npm run verify`：21 / 21 项通过。包含全片音视频解码、精确时长与帧数、所有结尾帧纯黑、结尾音轨逐样本为零、乱序时间采样一致、中文字形覆盖、实际导出文件和源文件哈希对应。
- `node scripts/browser-verify.mjs`：13 / 13 项通过。包含移动视口比例、预览音画推进与暂停、实际 MP4 加载／跳转／播放／声音解码，以及浏览器解码的黑场与静音结尾。
- 从最终编码的 MP4 抽取 33 个时刻进行画面检查，覆盖每种文明形态、字形特写、汇聚、完整包装及结尾。审片 ZIP 包含这些 PNG 和联系表。
- 音轨实测约 −13.98 LUFS、−1.78 dBTP；未使用外部音乐、采样库或付费服务。

浏览器测试中修复了检查脚本在页面初始化完成前访问渲染 API 的时序问题；重新运行后全部通过，不改变成片内容。

实际验证环境为 Linux、FFmpeg 和 Chromium。未进行实体手机播放器测试或实体耳机／扬声器试听；播放器及数字音频检查已完成。主观音色和具体设备表现不由自动检查代替。
