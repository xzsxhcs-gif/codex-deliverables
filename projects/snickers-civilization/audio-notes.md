# 原创程序音轨

《SNICKERS：文明的底层代码》的声音完全由 `scripts/audio.py` 合成。没有采样库、网络音效、现成歌曲、语音模型或付费 API。固定随机种子 `0x534e4943` 控制所有鼓皮噪声、金属声、纸张摩擦与空气底噪；从头运行脚本可以重建音轨。

## 运行

需要 Python 3、NumPy、SciPy 与 FFmpeg：

```sh
python3 -m pip install numpy scipy
python3 scripts/audio.py
```

生成 `public/audio/soundtrack.wav`（48 kHz / 24-bit PCM / 立体声）、`public/audio/soundtrack.m4a`（AAC-LC / 128 kbps），以及 `public/audio/audio-validation.json`。完整时长 50 秒，每声道 2,400,000 个 PCM 采样。WAV 用于最终影片；M4A 用于网页预览。

## 配器与剪辑时间

150 BPM，一拍 0.4 秒，对应 30 FPS 的 12 帧。主要旋律由 D 小调音高构成；文明阶段保留同一音高序列，并改变配器、排列和细分。八个文明阶段各五拍，避免把每次历史转场都做成相同的四拍循环。

| 时间 | 声音功能 |
| --- | --- |
| 0–6.4 s | 路径绘制短音、逐渐密集的构造脉冲、低音轮廓和第一次上升声。 |
| 6.4–16 s | 合成电声短旋律、开放五度和弦、四种交替的切分鼓型、低音钩子。 |
| 16–18 s | 图腾：音高鼓皮与五拍分组。 |
| 18–20 s | 纹样：纯合成共振峰与长音和声，不使用人声录音。 |
| 20–24 s | 几何／星图：同一旋律的高八度、声像旋转与相位式重排。 |
| 24–26 s | 徽章：短促铜管式谐波和弦与鼓组重音。 |
| 26–28 s | 公式：旋律以确定性的音高置换和 0.125 秒细分展开。 |
| 28–32 s | 电路／数字：0.1 秒细分、短门限音色、逐层增加的事件密度。 |
| 32–40 s | 回收：旋律反向排序，鼓花加密；结构重音对齐 32 / 33.6 / 35.2 / 36.8 / 38.4 秒。 |
| 40–43.2 s | 连续上行、鼓花与短暂抽空，把汇聚集中到一个落点。 |
| 43.2 s | 完整和弦、低音冲击和顶部旋律同时落地。 |
| 44.8 s | 音乐骤停；10 ms 退坡避免非设计性的数字爆音。 |
| 45.25–49.3 s | 极小的程序包装纸摩擦、一个普通拨弦音与低声房间底噪。 |
| 49.5–50 s | 完全数字静音。 |

底鼓由降频正弦、倍频鼓腔和短噪声攻击组成；军鼓分离鼓皮、金属响弦与瞬态；镲片由六组互不成整数比的方波与滤波噪声构成。低音为有限谐波与轻失真；旋律采用谐波衰减，各音色保留共同的音高基因。短促、错开的立体声反射营造空间，避免长混响盖住卡点。轻微的底鼓侧链让低频和节奏分离。

## 实际验证

初版实测：约 **−13.98 LUFS**、**−1.78 dBTP**、**6.8 LU** 响度范围。FFmpeg `astats` 采样峰值 −1.783 dBFS、整体 RMS −16.545 dBFS；直流偏置约 0.000002。48 kHz 立体声与 50 秒时长已通过 `ffprobe` 核对；AAC 完整解码没有错误。频谱检查覆盖低频、低中频、中频、高频和高频空气感；末尾 0.5 秒 PCM 所有样本均为零。

响度采用 FFmpeg 两遍测量与归一化，目标 −14 LUFS / −1.8 dBTP。实时测量值和同步事件列表以生成的 JSON 为准。验证包含数字音频与解码检查，未声称经过实体耳机或扬声器试听。
