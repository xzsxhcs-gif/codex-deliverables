# Codex 成果交付仓库

用于保存本对话任务的源工程、交付文档和下载入口。

## 交付方式

- 源码和文档按项目保存在 `projects/`。
- 视频、音频与大型压缩包优先作为 [Release 附件](https://github.com/xzsxhcs-gif/codex-deliverables/releases) 提供下载。
- 每次上传后核验实际文件，并在对话中提供具体文件或版本链接。
- 本仓库为公开仓库，公开内容无需登录即可访问。
